---
name: plan-project
description: Break a project or large task into a plan: milestones, ordered steps, risks and what is unknown — kept as a todo list.
license: Apache-2.0
---
1. Restate the goal and what 'done' means; ask about anything that changes the plan (clarify).
2. Explore just enough to plan (list_files, read the README and main modules).
3. Split into milestones that each leave something working; under each, steps of an hour or less.
4. Put the steps in todo_write in order; mark dependencies and the riskiest step (do it early).
5. List assumptions and unknowns; update the todo list as work goes and say when the plan changes.
