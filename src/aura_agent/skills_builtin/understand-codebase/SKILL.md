description: Get oriented in an unfamiliar project quickly.
license: Apache-2.0
---
1. Read the README, then the build/config files (pyproject, package.json, Makefile, Dockerfile).
2. List the top-level layout (list_files) and find the entry points (main, cli, app, server).
3. Follow one real request/command end to end with code_nav.
4. Run the tests once to see the project's state.
5. Summarise: what it does, how it's organised, how to run and test it, anything surprising. Save durable facts with memory_write.
