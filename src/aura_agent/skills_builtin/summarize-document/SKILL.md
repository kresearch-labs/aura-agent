---
name: summarize-document
description: Summarize a long document, PDF, page or meeting notes faithfully: the main points, decisions and open questions, with where each came from.
license: Apache-2.0
---
1. Read the whole document (read_file / web_crawl; long ones in parts) before writing.
2. Lead with the 3-5 points that matter most for the user's purpose (ask what it's for if unclear).
3. Keep numbers, names and dates exactly as written; quote short key phrases instead of paraphrasing them.
4. Separate what the document says from your own reading; list decisions, owners and open questions.
5. Say where each point is (page, section, heading) so the user can check it.
