description: Research a question on the web and answer with checked sources.
license: Apache-2.0
---
1. Split the question into 2–5 sub-questions.
2. Search (web_search), then open the best pages (web_crawl) — prefer official docs, papers, primary sources over blogs.
3. For each claim keep the page it came from; quote exactly or paraphrase without quote marks.
4. Use a number only if the page you cite says it (Aura checks this).
5. Answer with the sources listed; say what you could not confirm.
