---
name: write-readme
description: Write or improve a project's README from what the code really does.
license: Apache-2.0
---
1. Read the code's entry points and config — document what exists, not what you guess.
2. Sections: what it is (2 lines), install, quick start (a command that really works — run it), configuration, how to test, licence.
3. Keep examples copy-pasteable and correct for every OS the project supports.
4. Show the diff before writing over an existing README.
