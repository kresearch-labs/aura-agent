---
name: draft-message
description: Draft an email, message or announcement for the user to send: clear ask, right tone, short — never sent by Aura.
license: Apache-2.0
---
1. Find out who it's for, what the reader must do or know, and the tone (ask if unclear).
2. First line: the point or the ask. Then the context needed, then details. One topic per message.
3. Short sentences, no jargon the reader won't know; a clear deadline or next step.
4. Write it to a file or show it in the answer — Aura never sends messages; the user does.
5. Offer one shorter alternative if the draft is long.
